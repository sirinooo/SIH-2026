# SasyaSetu — SIH 2026 Demo (PS 26132)

**Problem Statement (SIH-26132):** Strengthening market linkages and price discovery for farmers
**Department:** Skills, Employment, Entrepreneurship and Innovation — Government of Maharashtra

This is a **clickable demo prototype** (single self-contained `index.html` — no build, no server, no internet needed). Open it by double-clicking, or view it live on GitHub Pages via the URL shown in the repo's Settings → Pages.

## What it demonstrates
A proposed platform that connects farmers directly to verified buyers and helps them make better selling decisions:

### Three portals (choose on the landing page)
- **Farmer / FPO** — daily mandi prices, price comparison across mandis (bar chart), 14-day price trends by mandi, "When to Sell" advice (uses 3-year history + weather + live diesel price), list lots, see verified buyer offers.
- **Buyer / Trader** — verified buyer dashboard to browse lots and place offers.
- **Department Admin** — buyer verification, grievances, lots & payments, price feeds (e-NAM / AGMARKNET), FPO onboarding, market analytics.

### Key features shown
- **When-to-Sell intelligence** — the model advises "sell now / wait 7 / wait 15 days" with net expected gain after storage, fuel and transport costs.
- **Price discovery** — comparison bar chart of onion prices across mandis + multi-line price trends.
- **Language toggle** — full English ⇄ मराठी (Marathi) interface.
- **Verification & trust** — verified buyers, FPO onboarding, lot tracking till payment.

> **Note:** All data shown is **illustrative/demo** data. Prices and figures are placeholders for the pitch, not real market data.

## How to run
1. Open the repo → Actions/Pages or just use the published URL.
2. Or download `index.html` and double-click it.
